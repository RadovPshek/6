# Лабораторная работа №6: Оценка качества работы алгоритмов классификации и кластеризации

На основе предыдущих лабораторных работ необходимо написать программу, оценивающую
результаты работы различных алгоритмов кластеризации и классификации
(k-means, kNN, SVM, DBSCAN).

## Структура проекта

```
src/
├── external_metrics.py   метрики внешнего оценивания (часть 1)
├── internal_metrics.py   метрики внутреннего оценивания (часть 2)
└── dbscan.py             алгоритм кластеризации DBSCAN (часть 3)
```

## Часть 1 Внешнее оценивание (`src/external_metrics.py`)

Реализовать следующие функции:

| Функция              | Описание                                                       |
|----------------------|----------------------------------------------------------------|
| `confusion_matrix`   | Матрица неточностей (confusion matrix)                         |
| `precision_score`    | Точность (precision), поддержка `average='macro'` и `None`     |
| `recall_score`       | Полнота (recall), поддержка `average='macro'` и `None`         |
| `f1_score`           | F1-мера, поддержка `average='macro'` и `None`                  |
| `roc_curve`          | ROC-кривая: вычисление FPR, TPR при различных порогах          |
| `mean_squared_error` | Среднеквадратичная ошибка (MSE)                                |
| `cross_val_score`    | K-fold кросс-валидация                                         |

## Часть 2 Внутреннее оценивание (`src/internal_metrics.py`)

Реализовать следующие функции:

| Функция               | Описание                                                      |
|-----------------------|---------------------------------------------------------------|
| `r_squared_score`     | Коэффициент детерминации R² (для случая без известного разбиения) |
| `silhouette_score`    | Коэффициент силуэта                                           |
| `dunn_index`          | Индекс Данна                                                  |
| `davies_bouldin_index`| Индекс Девиса-Болдина (DBI)                                   |
| `dbcv_score`          | Индекс валидности по плотности кластеризации (DBCV)           |

## Часть 3 Алгоритм DBSCAN (`src/dbscan.py`)

Реализовать метод `predict` класса `DBSCANClustering`:

1. Для каждой точки найти соседей в радиусе `eps`.
2. Точки с числом соседей >= `min_samples` — ядровые (core points).
3. Из ядровых точек расширять кластеры: добавлять соседей
   и рекурсивно расширять через ядровые точки.
4. Точки, не попавшие ни в один кластер — шум (метка -1).

## Требования

Функции, реализующие указанные способы оценки качества, должны быть реализованы
студентом самостоятельно. Допускается использование готовых примитивов из стандартных
или сторонних библиотек для выполнения базовых (в т.ч. векторизованных) операций
(сложение, умножение, возведение в степень, вычисление среднего значения и т.п.).
